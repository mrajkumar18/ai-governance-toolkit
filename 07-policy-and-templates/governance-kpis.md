# Governance KPIs

Report quarterly to the AI Governance Committee. Start with 5-7; add as maturity grows.

| KPI | Definition | Target (example) |
|---|---|---|
| Register coverage | AI systems in the register ÷ systems discovered (survey, procurement, [shadow-AI discovery](../docs/shadow-ai-discovery.md) methods) | ≥ 95% |
| Tiering coverage | Registered systems with a documented tier | 100% |
| Assessment completion | Tier 1-2 systems with a current impact assessment | 100% Tier 1; ≥ 90% Tier 2 |
| Gate compliance | Live systems that passed all required gates | 100% |
| Gate cycle time | Median days from intake to G2 decision, by tier | Tier 3 ≤ 10; Tier 2 ≤ 30 |
| Review currency | Systems with overdue reviews | 0 |
| Open high risks | High / critical risks beyond agreed due date | 0 |
| Exceptions | Active exceptions and those past expiry | Trend down; 0 past expiry |
| Incidents | AI incidents and near misses by severity; mean time to contain | Sev 1: 0; falling trend |
| Training | Staff in AI-relevant roles trained | ≥ 90% |
| Oversight effectiveness | Tier 1 systems whose override rate, review time and reviewer miss rate are inside the monitoring-plan thresholds | 100% |
| Significant-change compliance | Significant changes with a completed [checklist](../04-lifecycle-gates/significant-change-checklist.md) before release | 100% |
| Vendor assurance | Third-party AI with a completed assessment | 100% for Tier 1-2 |

*Targets are examples; set them with the Committee.*
