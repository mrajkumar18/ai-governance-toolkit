# 06 · Impact Assessment

An AI impact assessment asks: **who could be affected, how, and what are we doing about it?** It combines ideas from the EU AI Act's fundamental-rights impact assessment (Art. 27), ISO/IEC 42001 impact assessment (clauses 6.1.4 / 8.4, Annex A.5), NIST AI RMF MAP 5, and GDPR / DPDPA data-protection impact assessments, so one document can serve several purposes.

| File | Purpose |
|---|---|
| [`ai-impact-assessment-template.md`](ai-impact-assessment-template.md) | Blank template (full form; Tier 2 may complete sections marked ◐ only) |
| [`example-loan-prescreening-impact-assessment.md`](example-loan-prescreening-impact-assessment.md) | A completed **fictional** example for a high-risk (Tier 1) predictive-model use case |
| [`example-portfolio-agent-impact-assessment.md`](example-portfolio-agent-impact-assessment.md) | A completed **fictional** short-form example (Tier 2) for a GenAI multi-agent system |

Section **4A** of the template (cross-border transfer assessment) is also the only section a Tier 3 system needs when it sends personal data across borders.

> The example uses a fictional bank and illustrative figures. It is a teaching aid, not legal advice or a template for any real institution's decision.
