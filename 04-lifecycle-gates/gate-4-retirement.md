# Gate 4: Retirement

**Purpose:** Retire a system without leaving data, access or obligations behind.

## Checklist
- [ ] Decision and reason recorded; affected users and dependent systems notified
- [ ] Replacement or fallback process in place
- [ ] Access revoked: users, service accounts, API keys, agent credentials (TK-12)
- [ ] Data retention and deletion decided and executed for training data, prompts, logs, embeddings and outputs (TK-23)
- [ ] Models, prompts and artefacts archived or destroyed per policy (TK-23)
- [ ] Documentation and logs retained for the required period (TK-23)
- [ ] Vendor contract closed; vendor deletion confirmed in writing (TK-15)
- [ ] Open incidents and complaints closed or transferred (TK-18, TK-19)
- [ ] Lessons learned captured
- [ ] Register status set to **Retired**, with date (TK-02)

## Required evidence
Retirement decision · Access revocation record · Data deletion certificate · Archive record · Vendor confirmation
