# 03 · Control Mapping

One control set, mapped to many frameworks, so the organisation runs **one** program instead of several parallel compliance efforts.

| File | Purpose |
|---|---|
| [`control-mapping-matrix.csv`](control-mapping-matrix.csv) | 26 control themes mapped to NIST AI RMF 1.0, ISO/IEC 42001:2023, EU AI Act (Reg. 2024/1689), ISO/IEC 27001:2022, GDPR, India's DPDPA 2023 and RBI FREE-AI pillars (advisory), with evidence and the gate where each is checked |
| [`mapping-notes.md`](mapping-notes.md) | How to read the matrix, caveats, and how to extend it |

Open the CSV in Excel, Google Sheets, or GitHub's table view.

**Columns:** control ID · theme · objective · framework references (×7) · typical evidence · gate · applies to.
